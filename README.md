# Counterintuitive Lab

Code for the experiments on the Counterintuitive Lab YouTube channel.
Each video is one simulation: change one thing that should obviously help, then measure what actually happens.

| # | Experiment | Folder |
|---|---|---|
| 001 | A free bridge makes everyone's commute longer (Braess's paradox) | [`experiments/001-free-bridge`](experiments/001-free-bridge) |

Every experiment runs on its own with Python 3.10+ and the packages in its `requirements.txt`.
